# Website tao QR code va Barcode

Trang web tinh de tao QR code hoac Barcode cho thong tin lo hang.

Noi dung ma duoc tao theo dinh dang:

```text
MA_LO_HANG-MA_SAN_PHAM-SO_LUONG-NHA_CUNG_CAP
```

Vi du:

```text
HD1235-SP1234-999-KHO1234
```

## Cach dung

Mo `index.html` bang trinh duyet, nhap thong tin va chon `QR code` hoac `Barcode`.

## Publish

Co the upload truc tiep `index.html` len GitHub Pages, Netlify Drop, Vercel hoac bat ky static hosting nao.
